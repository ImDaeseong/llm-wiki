# 05. 집 ↔ 회사 다기기 동기화

GitHub Gist를 공유 저장소로 사용해 여러 기기에서 같은 WIKI 데이터를 씁니다.

---

## 동작 원리

```
집 PC (Chrome)          GitHub Gist           회사 PC (Chrome)
    WIKI 앱  ──저장──▶  llm-wiki-data.json  ◀──불러오기──  WIKI 앱
    크롬 확장 ──1시간 자동동기화──────────────────────────  크롬 확장
```

- 데이터는 비공개 Gist에 JSON 형태로 저장됩니다
- 크롬 확장은 1시간마다 자동으로 최신 데이터를 가져옵니다
- WIKI 앱에서는 수동으로 저장/불러오기를 실행합니다

---

## 최초 설정 (집 PC 기준)

### 1. Gist 생성

1. WIKI 앱 접속 → 모든 정보 입력 및 저장
2. 사이드바 하단 **GitHub Token** 입력 (Token 발급 방법: [01-설치가이드.md](01-설치가이드.md))
3. **저장** 클릭 → Gist 자동 생성
4. **Gist ID** 필드에 표시된 ID를 메모장 등에 복사해 둠

---

## 신규 기기 추가 (회사 PC)

### WIKI 앱에서 불러오기

1. WIKI 앱 접속
2. 사이드바 하단 **GitHub Token** 입력
3. **Gist ID** 필드에 집 PC에서 메모한 ID 직접 입력
4. **불러오기** 클릭 → 집 PC의 데이터가 이 기기에 복원됨

이후에는 저장 시 같은 Gist가 업데이트됩니다.

### 크롬 확장 설정

1. 확장 아이콘 클릭 → 팝업 열기
2. **GitHub Token** 입력
3. **Gist ID** 입력 (위에서 메모한 값)
4. **저장** → **지금 동기화** 클릭

---

## 일상적인 동기화 워크플로우

### 데이터를 수정했을 때 (어느 기기든)

```
WIKI 앱 각 섹션 저장 버튼 → (로컬 저장)
사이드바 하단 저장 버튼 → (Gist 업로드)
```

### 다른 기기에서 수정된 데이터를 반영할 때

```
사이드바 하단 불러오기 버튼 → (Gist에서 로컬로 복원)
```

### 크롬 확장은 자동

- 1시간마다 자동 갱신 (별도 조작 불필요)
- 즉시 반영이 필요하면 팝업 → **지금 동기화**

---

## 동기화 충돌 방지 수칙

Gist는 버전 히스토리를 유지하지만 자동 병합(merge)은 하지 않습니다. 아래 수칙을 따르면 충돌을 최소화할 수 있습니다.

1. **수정 전에 불러오기**: 편집을 시작하기 전에 반드시 **불러오기**를 먼저 실행
2. **수정 후 즉시 저장**: 편집이 끝나면 바로 **저장** 실행
3. **동시 편집 금지**: 집과 회사에서 동시에 같은 데이터를 수정하지 않도록 주의

### 충돌이 발생했다면

Gist 웹 페이지에서 히스토리를 확인할 수 있습니다:
1. [gist.github.com](https://gist.github.com) 접속
2. `llm-wiki-data.json` Gist 클릭
3. **Revisions** 탭에서 이전 버전 확인

---

## 주의 사항

- GitHub Token은 각 기기에서 별도로 입력해야 합니다 (보안상 Gist에 저장되지 않음)
- Token은 브라우저 메모리에만 유지되므로 새로고침 후 재입력 필요
- 크롬 확장의 Token은 `chrome.storage.local`에 저장되어 브라우저 재시작 후에도 유지됨

## Gist 데이터 구조 참고

저장되는 JSON 형태:

```json
{
  "profile": { "name": "...", "role": "...", ... },
  "stack": [{ "name": "MFC", "level": "전문가", "desc": "..." }],
  "prefs": { "claude": "...", "common": "..." },
  "notes": [{ "id": 1234, "title": "...", "cat": "학습", ... }],
  "projects": [{ "name": "...", "status": "진행중", ... }],
  "decisions": [{ "title": "...", "why": "...", ... }],
  "saved_at": "2026-06-22T10:00:00.000Z"
}
```
