# 02. 크롬 확장 프로그램 설치 및 사용법

크롬 확장은 AI 사이트(claude.ai, chatgpt.com, gemini.google.com, perplexity.ai)에 WIKI 컨텍스트를 자동 주입합니다.

---

## 설치

### 1. 확장 파일 준비

이 저장소의 `wiki-extension/` 폴더를 로컬에 저장합니다.

```
wiki-extension/
├── manifest.json
├── popup.html
├── background.js
└── content_script.js
```

### 2. 크롬에 로드

1. 크롬 주소창에 `chrome://extensions/` 입력
2. 오른쪽 상단 **개발자 모드** 토글 활성화
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. `wiki-extension/` 폴더 선택

설치 완료 후 주소창 오른쪽 퍼즐 아이콘에서 **LLM WIKI** 고정 가능.

---

## 초기 설정 (팝업)

확장 아이콘 클릭 → 팝업 열기

| 필드 | 입력 값 |
|------|---------|
| GitHub Personal Access Token | `ghp_xxxx...` |
| Gist ID | WIKI 앱 저장 후 생성된 ID |

**저장** 버튼 클릭 → **지금 동기화** 클릭 → "동기화 완료" 확인

### 주입 항목 선택

팝업 하단에서 AI에게 전달할 항목을 선택합니다.

| 항목 | 권장 | 설명 |
|------|------|------|
| 프로필 & 환경 | ✅ 항상 | 역할, IDE, 언어 |
| 기술 스택 | ✅ 항상 | 숙련도별 기술 목록 |
| AI 공통 지침 | ✅ 항상 | 코딩 컨벤션, 답변 형식 |
| 진행 중인 프로젝트 | 선택 | 현재 작업 맥락이 필요할 때 |
| 최근 노트 5개 | 선택 | 학습 내용 이어서 질문할 때 |

**항목 저장** 버튼으로 선택을 보존합니다.

---

## WIKI 주입 사용법

### 기본 흐름

1. claude.ai, chatgpt.com 등 AI 사이트 접속
2. 화면 우하단에 두 개 버튼이 나타납니다:
   - 보라색 **WIKI 주입** 버튼
   - 초록색 **선택 저장** 버튼
3. **WIKI 주입** 클릭 → 입력창에 나의 컨텍스트가 자동 삽입됨
4. 이어서 질문 내용 작성 후 전송

주입 성공 시 버튼이 **"주입됨 ✓"** 로 3초간 바뀝니다.

### 각 AI별 동작 방식

| AI 사이트 | 입력 방식 | 비고 |
|-----------|-----------|------|
| claude.ai | ProseMirror (contentEditable) | execCommand로 주입 |
| chatgpt.com | textarea (React) | native setter로 주입 |
| gemini.google.com | Quill (contentEditable) | execCommand로 주입 |
| perplexity.ai | textarea | native setter로 주입 |

---

## 선택 저장 사용법

웹 페이지의 유용한 내용을 바로 WIKI 노트로 저장합니다.

### 방법 1 — 버튼 클릭
1. 저장할 텍스트를 마우스로 드래그 선택
2. **선택 저장** 버튼 클릭
3. 현재 페이지 제목 + 선택 텍스트 + URL이 노트로 저장됨

### 방법 2 — 우클릭 메뉴
1. 텍스트 선택 후 우클릭
2. **WIKI 노트로 저장** 클릭

저장 성공 시 확장 아이콘에 녹색 **✓** 뱃지가 잠깐 표시됩니다.
저장된 노트는 WIKI 앱 → **노트 & 메모** 페이지에서 확인할 수 있습니다.

---

## 자동 갱신

확장은 **1시간마다** Gist에서 최신 WIKI 데이터를 자동으로 가져옵니다. 수동으로 갱신하려면 팝업에서 **지금 동기화**를 클릭하세요.

---

## 문제 해결

| 증상 | 해결 방법 |
|------|-----------|
| 버튼이 나타나지 않음 | 페이지 새로고침, AI 사이트가 업데이트된 경우 확장 재설치 |
| "WIKI 데이터가 없습니다" | 팝업에서 Gist ID 확인 후 동기화 |
| 주입 후 전송이 안 됨 | 텍스트 클릭 후 직접 Enter — 일부 AI는 포커스 재설정 필요 |
| 저장 실패 | Token 만료 여부 확인, Gist 권한(scope) 확인 |
