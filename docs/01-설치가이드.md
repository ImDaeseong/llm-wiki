# 01. WIKI 앱 설치 및 초기 설정

## 1단계 — WIKI 앱 접속

브라우저에서 아래 주소를 엽니다.

```
https://imdaeseong.github.io/llm-wiki/
```

> **로컬 사용**: `index.html` 파일을 직접 브라우저로 열어도 됩니다 (`file://` 프로토콜). Gist 동기화와 Claude API는 로컬에서도 동작합니다.

---

## 2단계 — 나의 정보 입력

왼쪽 사이드바 순서대로 작성합니다.

### 프로필 & 환경
- **이름 / 역할**: AI가 호칭과 수준을 파악하는 기준
- **주요 업무**: 구체적일수록 AI가 맥락에 맞는 답변을 합니다
- **경력 / 전문 분야**: 숙련도를 명시하면 설명 깊이가 달라집니다
- **주 IDE / 언어**: 코드 예제의 환경 기준이 됩니다
- **코딩 스타일**: 헝가리안 표기법, 들여쓰기, 명명 규칙 등
- **답변 선호**: "코드 위주", "한국어 주석", "단계별 설명" 등

저장 버튼을 누르면 브라우저 `localStorage`에 저장됩니다.

### 기술 스택
기술별로 이름, 설명, 숙련도를 추가합니다.

| 숙련도 | 기준 |
|--------|------|
| 전문가 | 주력 기술, 심층 질문 가능 |
| 고급   | 업무에 자주 사용 |
| 중급   | 사용 경험 있음 |
| 입문   | 학습 중 |

### AI 사용 선호
- **Claude / ChatGPT / Gemini별 용도**: 각 AI에게 어떤 종류의 질문을 하는지 기록
- **공통 지시사항**: 모든 AI에게 항상 전달할 내용 (코딩 컨벤션, 언어, 포맷 등)

## 3단계 — GitHub Gist 동기화 설정

데이터를 클라우드에 저장해 여러 기기에서 사용합니다.

### GitHub Personal Access Token 발급

1. [github.com/settings/tokens](https://github.com/settings/tokens) 접속
2. **Generate new token (classic)** 클릭
3. Note: `llm-wiki` 입력
4. 만료일: 원하는 기간 선택 (No expiration 권장)
5. 권한: **gist** 체크박스만 선택
6. **Generate token** 클릭 → 토큰 복사 (`ghp_xxxx...` 형태)

> ⚠️ 토큰은 생성 직후 한 번만 표시됩니다. 반드시 복사해 두세요.

### WIKI 앱에 Token 입력

1. 왼쪽 사이드바 하단 **GitHub Token** 필드에 붙여넣기
2. **저장** 버튼 클릭 → 처음 실행 시 새 Gist가 자동 생성됩니다
3. **Gist ID** 필드에 ID가 자동으로 입력됩니다 — 이 값을 메모해 두세요

저장 후 `https://gist.github.com/` 에서 `llm-wiki-data.json` 파일을 확인할 수 있습니다.

---

## 4단계 — 데이터 확인

- **저장**: 사이드바 각 섹션의 **저장** 버튼 → 로컬 저장 → 사이드바 하단 **저장** 버튼 → Gist 업로드
- **불러오기**: 사이드바 하단 **불러오기** 버튼 → Gist에서 로컬로 복원

---

## 데이터 저장 위치 정리

| 데이터 | 위치 | 비고 |
|--------|------|------|
| 프로필, 스택, 선호도, 노트 등 | 브라우저 `localStorage` | 브라우저별 독립 |
| 동기화 데이터 | GitHub Gist (비공개) | 무료, 기기 간 공유 |
| Gist ID | `localStorage` | 첫 저장 후 자동 보관 |
| GitHub Token | 브라우저 메모리 | 새로고침 시 재입력 필요 |
| Anthropic API Key | 브라우저 메모리 | 새로고침 시 재입력 필요 |
| OpenAI API Key | 브라우저 메모리 | 새로고침 시 재입력 필요 |

API 키와 GitHub Token은 `localStorage`, Gist, 저장소에 기록하지 않습니다. AI 요청이
성공하거나 실패하면 선택한 제공자의 키를 즉시 지우고, 페이지가 숨겨지거나 종료될 때
전체 입력값을 다시 지웁니다. `API 키 즉시 지우기` 버튼으로 바로 폐기할 수도 있습니다.
브라우저에 직접 API 키를 입력하는 방식은 사용 중인 브라우저 확장,
악성 스크립트 등에 의한 탈취 위험까지 제거하지 못하므로 개인 로컬 환경에서만 사용하고,
공용 PC에서는 사용하지 마세요. 운영·공개 서비스에서는 별도 백엔드와 환경변수 기반 키
관리가 필요합니다.

OpenAI 질문은 Responses API의 JSON Schema 형식으로 요청하고 `store: false`를 지정합니다.
응답이 길이 제한 등으로 중간에 끊기더라도 화면에는 JSON 원문 대신 복구 가능한 답변
본문만 표시합니다.
