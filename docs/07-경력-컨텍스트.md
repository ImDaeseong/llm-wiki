# 경력 컨텍스트

`career-context.js`는 공개 `career/index.html`의 이력만 LLM WIKI 구조로 옮긴 초기 데이터입니다.

## 반영 범위

- 프로필: 역할, 주요 업무, 전체 경력, 회사 이력
- 교육: 인제대학교 정보컴퓨터학부 컴퓨터네트워크전공
- 자격: 정보처리기사
- 기술: 공개 이력의 언어, Windows, 네트워크, 모바일, 데이터베이스, 배포, 개발 도구
- 프로젝트: PC방 플랫폼, Android O2O, 해외 구축, KT KAPS, 가상주민번호, 업무용·닷넷 플랫폼, 웹·무선인터넷 서비스
- 현재 개발 중심: AI 바이브 코딩 기반의 개인 AI 운영·에이전트·작업 이력·프롬프트·창작 자동화·경력·검수·지식관리·공개 스킬 개발
- 최근 AI 포트폴리오: `ai-workspace`, `ai_agent`, `ai_history_dashboard`, `ai_prompt`, `ai_test`, `ai_test1`, `ai_test2`, `career`, `hermes-agents`, `llm-wiki`, `qa_manager`, `skills`

연락처는 AI 작업에 필요하지 않으므로 옮기지 않습니다. 공개 이력에 기술별 숙련 등급이
없기 때문에 초기 등급은 `경력 확인`으로 표시하며, `전문가`나 `고급`으로 추정하지 않습니다.
다만 Android는 사용자가 상용 앱 3개를 개발·운영했다고 직접 확인했으므로
`상용 개발·운영`으로 표시합니다.

## 기존 데이터 보호

브라우저에 사용자가 작성한 값이 있으면 유지합니다. 비어 있는 프로필 필드와 누락된
기술·프로젝트만 추가하고, 과거 버전의 샘플 기술 목록만 실제 경력 기술로 교체합니다.
과거의 일반적인 `개인 프로젝트·AI 활용 개발 연구` 초기 항목은 설명이 수정되지 않은
경우에만 12개 저장소 기반 포트폴리오로 교체합니다. 같은 이름이라도 사용자가 설명을
직접 바꾼 항목은 유지합니다.

## 외부 AI 전송

확장에서 프로필 주입을 켜면 역할·경력·학력·자격·주요 경력이 Claude, ChatGPT,
Gemini 또는 Perplexity의 현재 대화 입력창에 삽입됩니다. 사용자가 승인한 공개 경력만
대상이며 이메일과 기타 연락처는 포함하지 않습니다.
